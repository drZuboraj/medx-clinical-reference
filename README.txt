MEDx separated-file website

Files:
- index.html: page structure
- style.css: appearance and layout
- app.js: search, rendering and interactions
- data/medicines.json: existing clinical data and source metadata

IMPORTANT: Upload all files/folders preserving this structure to the ROOT of the GitHub Pages repository. Do not upload only index.html. Keep your original downloaded ZIP backup.

The clinical data was extracted from the supplied MEDx prototype without intentionally changing its content. This does not independently verify the clinical accuracy or completeness of the entries.
